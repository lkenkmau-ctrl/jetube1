# ЖеТуб - Клон YouTube

## 1. Обзор проекта
- **Название:** ЖеТуб (Jetube)
- **Тип:** Full-stack веб-приложение (видеохостинг)
- **Суть:** Рабочий клон YouTube с загрузкой, просмотром и управлением видео
- **Целевые пользователи:** Демонстрация навыков, локальное использование

## 2. Технологический стек

### Backend
- **Платформа:** Node.js + Express.js
- **Порт:** 5000
- **Статика:** /uploads - хранилище видео и превью
- **API Endpoints:**
  - `GET /api/videos` - список всех видео
  - `GET /api/videos/:id` - получить видео по ID
  - `POST /api/upload` - загрузить видео
  - `DELETE /api/videos/:id` - удалить видео
  - `GET /api/stream/:id` - потоковая передача видео

### Frontend
- **Платформа:** React 18 (Vite)
- **Порт:** 5173 (dev)
- **Роутинг:** React Router v6

### Туннелирование
- **Решение:** localtunnel (бесплатный, не требует регистрации)
- **Команда:** `npm run tunnel` - создаёт публичный туннель

## 3. UI/UX Спецификация

### Цветовая палитра
- **Фон основной:** #0f0f0f (тёмный как YouTube)
- **Фон карточек:** #1a1a1a
- **Акцент:** #ff0000 (красный как у YouTube)
- **Текст основной:** #ffffff
- **Текст вторичный:** #aaaaaa
- **Ховер карточек:** #2a2a2a

### Типографика
- **Шрифт:** "Roboto", sans-serif
- **Заголовки:** 18px bold
- **Текст:** 14px regular
- **Мета-информация:** 12px

### Компоненты

#### Header (Шапка)
- Логотип "ЖеТуб" слева (красный акцент)
- Поисковая строка по центру (тёмная с серой рамкой)
- Кнопка "Загрузить" справа (красная)

#### Главная страница
- Сетка видеокартоок 4 колонки (desktop), 2 (tablet), 1 (mobile)
- Карточка: превью 16:9, название, канал, просмотры, дата

#### Страница видео
- Плеер 16:9 с нативными controls
- Под плеером: название, описание, автор, дата
- Кнопка лайка/дизлайка

#### Страница загрузки
- Drag & drop зона
- Поле для названия и описания
- Прогресс загрузки

### Анимации
- Плавные transitions 0.2s ease
- Hover scale на карточках 1.02
- Fade-in при загрузке
